## ⚛️ Density Functional Theory (DFT) & Materials Science

### [**VASP-automatization-platform**](https://github.com/carlosraulps/VASP-automatization-platform){:target="_blank"}
*   **Description**: An AI-driven platform for high-throughput Density Functional Theory (DFT) calculations using VASP. It transitions from linear scripting to a modular, event-driven architecture designed for scalability.
*   **Language**: Python 🐍
*   🔗 [GitHub Repository](https://github.com/carlosraulps/VASP-automatization-platform){:target="_blank"}

### [**aird2d**](https://github.com/carlosraulps/aird2d){:target="_blank"}
*   **Description**: A project based on the Computational 2D Materials Database (C2DB) + custom code for training generative/discriminative ML models to predict and identify novel 2D materials from their structural and electronic properties.
*   **Language**: HTML / Python 🐍
*   🔗 [GitHub Repository](https://github.com/carlosraulps/aird2d){:target="_blank"}

## 🧮 Numerical Methods & Scientific Computing

### [**fortran-numerical-methods**](https://github.com/carlosraulps/fortran-numerical-methods){:target="_blank"}
*   **Description**: An open-source project providing efficient and well-organized implementations of various numerical methods (differential equations, root-finding, linear systems) in the Fortran programming language.
*   **Language**: Fortran ⚙️
*   🔗 [GitHub Repository](https://github.com/carlosraulps/fortran-numerical-methods){:target="_blank"}

### [**fortran-numerical-routines**](https://github.com/carlosraulps/fortran-numerical-routines){:target="_blank"}
*   **Description**: Numerical method implementations in Fortran 90 covering interpolation, integration, smoothing, root-finding, Monte Carlo, and more.
*   **Language**: Fortran ⚙️ (Forked/Extended)
*   🔗 [GitHub Repository](https://github.com/carlosraulps/fortran-numerical-routines){:target="_blank"}

### [**numerical-methods-in-matlab**](https://github.com/carlosraulps/numerical-methods-in-matlab){:target="_blank"}
*   **Description**: Matlab codes based on topics from my Fortran computational physics courses, translating algorithms to the Matlab environment.
*   **Language**: Matlab 📊
*   🔗 [GitHub Repository](https://github.com/carlosraulps/numerical-methods-in-matlab){:target="_blank"}
